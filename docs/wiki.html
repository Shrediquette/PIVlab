PIVlab Wiki

Guides for installing PIVlab, first steps and setting up PIV hardware. The user manual explains every part of the program in detail.

You can run PIVlab in three ways: as a standalone app on Windows (no MATLAB needed), as a MATLAB toolbox, or in the browser with MATLAB Online (limited features). The guides cover each of them.
