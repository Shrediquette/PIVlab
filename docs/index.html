PIVlab – free (stereo) particle image velocimetry software

PIVlab is free and open-source particle image velocimetry (PIV) software, and currently the most frequently cited PIV tool on the market. It analyses particle images and videos from any camera – from a smartphone or action camera to a scientific high-speed camera – calculates the velocity distribution, and derives, displays and exports many parameters of the flow. The graphical user interface makes PIV analyses fast and easy, also for beginners.

When your lab grows, PIVlab grows with it: together with OPTOLUTION's lasers, cameras and synchronizers, PIVlab also records the images itself, synchronized with the laser – and with two cameras even stereo-PIV.

Complete

Start with the images you already have, from any camera. When you add a PIV system from OPTOLUTION, PIVlab becomes more than analysis software: one program takes you from the camera to the result:

  • Control OPTOLUTION's lasers, synchronizers and cameras – developed together with PIVlab, so everything works hand in hand.
  • Record the image pairs, synchronized with the laser.
  • Create printable calibration boards.
  • Calibrate, analyse, validate and export.

No separate acquisition software, no copying files between programs. See Camera setup and Capturing images in the manual.

Expandable

Start with standard 2D PIV in minutes. When you need the velocity through the light sheet as well, add a second camera: PIVlab records both cameras synchronized, creates the calibration board and measures all three velocity components (stereo-PIV), with the same workflow. You can even try it before buying anything, with the built-in stereo-PIV simulator. Available from PIVlab 4.0.
