Deriving temporal parameters

Where spatial derivation works within one frame, this combines data across frames — averaging a whole time-resolved sequence into one representative result, or computing turbulence statistics.

Open via Plot → Temporal: Derive parameters (Ctrl+Shift+R).

Selecting which frames to include

Frames to process accepts the same range syntax used elsewhere in PIVlab — e.g. 1,3,4,8:10. Multiple rows give one averaged result per row, which is how a phase average works.

append to dataset (default) adds the result as a new frame alongside your existing data; replace all existing discards previous results first.

Available operations

Calculate mean, sum, stdev and TKE each work across the frames you selected.

Each button appends one new result frame. Click Remove current to delete the currently displayed (appended) frame if you don't want to keep it.

Stereo-PIV All operations include w, and the mean frames have to be made after the validation — see w in the rest of PIVlab.

Phase average of periodic flow

For a periodic (harmonic) flow — a flapping wing, a pulsating jet, a rotating machine — the Periodic (harmonic) flow section builds a phase average automatically, so you don't have to write out the multi-row frame ranges by hand.

  1. Set Frames to process to the frames covering the cycles you want to average (e.g. 1:end).
  2. Enter the number of frames that make up one period in Periodic (harmonic) flow.
  3. Click Calculate phase mean.

PIVlab groups every n-th frame together (frame 1, 1+n, 1+2n, … for the first phase, and so on) and appends one averaged frame per phase — a single representative period of the flow. It is the equivalent of entering [1:n:end; 2:n:end; … ; n:n:end] in Frames to process and calculating the mean, done in one click.

Do not include already-averaged frames in the selection, and make sure the frame count is a positive whole number — PIVlab warns you if either is wrong.
