Using PIVlab from the command line

Everything you do in the PIVlab window can also be done in a MATLAB script with the functions of the pivlab package. They use exactly the same code as the GUI, so a script and the GUI give identical results for identical settings. Every function works with only its required inputs and then uses the PIVlab defaults.

The workflow in ten lines

imgs = pivlab.readImages("Example_data/Jet_*.jpg", "pairwise");   % select and pair images
imgs = pivlab.preprocess(imgs);                                    % CLAHE + intensity stretch
res  = pivlab.analyze(imgs);                                       % PIV analysis
res  = pivlab.filter(res);                                         % remove outliers, interpolate
res  = pivlab.toMetric(res, DeltaT=0.001, PxPerMeter=1234);        % m and m/s
[res, vort] = pivlab.derive(res, "vorticity");                     % derived quantities
m    = pivlab.temporal(res, "mean");                               % temporal mean
pivlab.display(m, Overlay="magnitude");                            % figure like in the GUI
pivlab.saveSession(res, "analysis.mat");                           % open it in the GUI later

The PIVlab folder must be on the MATLAB path (addpath it, or start PIVlab once). Type help pivlab for an overview and help pivlab.analyze (etc.) for all options of a step. Complete examples are in Example_scripts/PIVlab_api_*.m.

The functions

The result struct

res holds all image pairs; the third dimension of the arrays is the pair.

FieldContent
res.x, res.yvector positions (px, or m after toMetric)
res.u, res.vvelocities in res.units (filtered after pivlab.filter, smoothed after a smoothed pivlab.derive)
res.u_raw, res.v_rawunfiltered PIV result
res.typevector1 = valid, 2 = removed/interpolated, 3 = second correlation peak, 0 = masked
res.correlation_mapcorrelation coefficient of every vector
res.derivedmaps computed by pivlab.derive, e.g. res.derived.vorticity
res.pxthe same data in pixel units, as PIVlab stores it internally

Settings

Name=value arguments change single settings. To reuse a complete configuration, pass a settings struct: from pivlab.defaults (then edit it), or from a file saved in the GUI.

s = pivlab.loadSettings("my_session.mat");       % session or settings file
imgs = pivlab.preprocess(pivlab.readImages("D:\run1\*.tif", "pairwise"), Settings=s);
res  = pivlab.analyze(imgs, Settings=s, Parallel=true);
res  = pivlab.filter(res, Settings=s);
res  = pivlab.toMetric(res, Settings=s);         % calibration of the session

Why pre-processing does not create new images

pivlab.preprocess only stores the settings (and computes the background image if requested). The filters are applied to every pair inside pivlab.analyze, exactly like the GUI does it, so long image series need no extra memory or disk space. pivlab.getImage shows a pre-processed image.

Requirements MATLAB R2021a or newer and the Image Processing Toolbox (as for the GUI). The Parallel Computing Toolbox is optional (Parallel=true).
